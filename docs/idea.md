# 高维小样本特征选择国内外研究现状与课题顶层规划

> **所属计算机细分方向**：高维小样本（HDLSS, High-Dimensional Low-Sample-Size，$p \gg n$）特征选择与分类
>
> **核心算法痛点**：维数灾难、强共线性（基因共表达）、极小样本下的严重过拟合、特征选择结果跨折不稳定

---

## 一、 国际前沿研究现状（四大主流技术路线）

国际计算机与生物信息学顶刊/顶会（*Pattern Recognition*、*IEEE TKDE/TNNLS*、*Bioinformatics*、*Briefings in Bioinformatics*、*ICML/NeurIPS* 等）近年主要围绕以下 4 条路线演进：

### 1. 集成特征选择与稳定性优化（EFS & Stability Selection）
* **现状**：单一特征选择算法在 HDLSS 数据上方差极大（样本微扰即导致筛选结果剧烈变化）。当前主流转向**异构集成（Heterogeneous EFS）**与**混合过滤-包裹框架（Hybrid Filter-Wrapper）**。
* **核心趋势**：评估范式从单一追求分类性能（AUC/ACC），转向同时优化**稳定性（Stability，跨重采样折的特征子集重叠度）**与**低冗余度（Redundancy）**，通过多准则秩聚合（Rank Aggregation）实现预测性能与子集精简度的帕累托最优。
* **与本课题的衔接**：本课题阶段 02 引入的 *Pattern Recognition* (2026) 集成秩聚合（EFS-RA）与 $50 \times 4$ 折重复分层交叉验证，已直接锚定在这一主流前沿线上。

### 2. 图/网络先验与拓扑约束方法（Graph / Network-Regularized FS）
* **现状**：针对基因间普遍存在的强共线性，传统 LASSO 等 $\ell_1$ 稀疏方法会在高度相关的基因群中“随机保留其一、丢弃其余”，导致生物学解释断层。国际前沿普遍将高维特征空间显式建模为**相关性网络或生物先验图**。
* **代表方法**：
  * **图卷积特征选择（GCN-FS）**：利用基因共表达网络或 PPI 网络作为结构先验，在图卷积与稀疏正则化过程中约束相连特征的权重平滑性，显著提升 HDLSS 场景下的泛化能力。
  * **网络社团中心方法**：例如 2026 年提出的 **RCC（Regression by Community Centers）**，将高维基因向量通过相变阈值构造成邻近网络，直接提取网络社团中心作为稳健代表特征，在极小样本与强噪声下表现出优于复杂知识图谱正则化模型（如 PLATO）的鲁棒性。

### 3. 面向 HDLSS 的稀疏神经网络与可微特征选择
* **现状**：常规深度神经网络在 $n < 100$ 的 Bulk RNA-seq 数据上极易严重过拟合。计算机领域因此发展出带**显式稀疏约束**的轻量级神经架构：
  * **LassoNet 及其鲁棒变体**：通过线性跳跃连接与层级 $\ell_1$ 稀疏约束实现非线性特征选择；2026 年的 **Robust LassoNet** 进一步引入 Huber/Cauchy 等鲁棒损失函数，专门缓解小样本中离群样本污染问题。
  * **可微特征选择（Concrete Autoencoder / Stochastic Gates）**：将离散的特征选择过程连续松弛化，通过端到端梯度下降直接选出最优 $k$ 个原始特征。
  * **事后可解释性归因（XAI）**：结合 GradientShap、DeepLIFT 等基于梯度或扰动的归因方法反推输入基因的重要性。

### 4. 表格基础模型（Tabular Foundation Models）的 HDLSS 适配
* **现状**：以 **TabPFN** 为代表的表格基础模型基于上下文学习（In-Context Learning），天然擅长极小样本分类，无需繁琐超参搜索。
* **瓶颈与突破**：原生 TabPFN 受限于上下文长度，通常仅支持 $\le 2,000$ 维特征。2026 年最新工作（如 **GOTabPFN**）正尝试通过“依赖图特征排序 + 紧凑 Tokenization”突破维度限制，将其推向基因表达谱等 HDLSS 场景。

## 二、 国内研究现状与痛点

国内在该方向呈现明显的**“应用层极卷、方法层分化”**格局：

1. **医工交叉 / 生信应用侧（占比最大）**：
   * 大量发表于 *Frontiers*、*BMC*、*Scientific Reports* 等期刊的研究，高度固化在**“多算法取交集范式”**（同时运行 LASSO、SVM-RFE、Random Forest、XGBoost 后画韦恩图取交集）。
   * **普遍短板**：① 缺乏严格的防数据泄露机制（常在全数据集做完差异筛选或标准化后再划分 CV，导致虚高 AUC）；② 忽视强共线性导致的“伪不稳定”；③ 算法层面无实质改进，纯粹调包。
2. **计算机 / 模式识别方法论侧**：
   * 国内强校团队主要在 *IEEE TNNLS*、*IEEE TKDE*、*Pattern Recognition*、*Briefings in Bioinformatics* 等顶刊发力。
   * **核心聚焦**：多视角/多组学稀疏学习、图拉普拉斯正则化（Graph Laplacian Regularized）特征选择、以及面向高维空间的改进群智能/进化特征搜索算法。

## 三、 本课题算法改进的三大高潜力切入点

结合主数据集 `GSE252027`（$n=22, p=1,141$）的极端小样本与时间窗口不均衡特征，后续算法改进应**避开硬套复杂深度学习的陷阱**，重点瞄准以下三个数学逻辑扎实的方向：

| 改进方向 | 核心算法思路 | 与本课题的契合度 |
| :--- | :--- | :--- |
| **1. 共线性感知的集成秩聚合（Collinearity-Aware EFS-RA）** | 在现有 EFS-RA 框架中引入基因共表达相关性惩罚或社团去冗余约束，并将“跨折稳定性”显式写入聚合权重。 | 无缝衔接阶段 02 工作；能从算法层面严格解释为何免疫桥梁基因 `Mrc1` 能在强纤维化共线性背景中被稳健识别。 |
| **2. 图正则化稀疏模型（Graph-Regularized Elastic Net）** | 将 `D3 ∩ D7` 共表达网络或通路先验构建为图拉普拉斯惩罚项加入目标函数，使相连基因共享平滑权重。 | 具备清晰的凸优化数学推导（计算机论文核心加分项），同时完美呼应“炎症—纤维化调控网络”的生物学机制。 |
| **3. 抗样本扰动的鲁棒特征选择** | 针对小样本中单个异常文库或分组不均衡（如 `D3` 仅 2 个样本）引发的权重剧烈抖动，设计鲁棒损失或自适应样本加权机制。 | 直接切中真实实验数据的痛点，研究动机极具说服力。 |

## 四、 研究生毕业课题与小论文“双轨推进”顶层规划

你的定位非常清晰，整个课题天然可以拆解为**“一条主线毕业、两类成果并行”**的架构：

### 1. 研究生毕业论文（大课题完整闭环）
* **定位**：计算方法创新 + 生物医学真实场景落地验证。
* **章节骨架**：
  1. **绪论**：心肌梗死后炎症—纤维化背景 + 高维小样本特征选择国内外研究现状。
  2. **数据构建与基准流程**：`GSE252027` 清洗、病理窗口锁定（`D3 ∩ D7`）与传统多算法基线对比。
  3. **核心算法创新（计算机核心章节）**：提出改进的高维小样本特征选择算法（数学推导、复杂度分析、公共数据集 Benchmark 与消融实验）。
  4. **多维度生信与药物验证**：将新算法筛选出的核心基因在外部 Bulk 队列（`GSE111059`、`GSE236374`）、单细胞数据（`GSE163465`）及芪参还五胶囊靶点网络中进行闭环验证。
  5. **湿实验交棒与验证（若有医院数据回流）**：呈现 2–5 个最终锁定靶点的湿实验结果，形成极强的学术闭环。

### 2. 学术小论文（独立发刊，不受湿实验周期掣肘）
* **定位**：聚焦**高维小样本特征选择算法优化**，投稿计算机/医工交叉期刊（如 *Computers in Biology and Medicine*、*IEEE JBHI*、*Briefings in Bioinformatics*、*Pattern Recognition*、*Knowledge-Based Systems* 等）。
* **关键避坑点（计算机审稿人必看）**：
  * **必须做多数据集 Benchmark**：不能只在 `GSE252027` 这一个数据集上证明新算法好，需要额外拉取 **5–10 个经典公开 HDLSS 基因表达基准数据集**（如 GEO/TCGA 癌症或心血管微阵列/RNA-seq 队列），与 LASSO、Elastic Net、RF、SVM-RFE、原版 EFS-RA 等基线做全面对比（对比指标：AUC/F1、特征子集稳定性 Kuncheva/Jaccard 指数、冗余度）。
  * **把心肌梗死课题作为 Flagship Case Study**：在算法论文的最后，将 `GSE252027` + 外部验证 + 单细胞定位作为真实生物医学案例分析（Case Study），瞬间拉开与纯调包水文的差距。

### 3. 给医院团队的湿实验交付（解耦推进）
* **策略**：无需等小论文发完才交棒。现阶段通过多算法与外部双队列已稳健锁定 8 个候选基因，待单细胞 `GSE163465` 定位和芪参还五胶囊靶点交集跑完，收敛到 2–5 个靶点后即可先交棒给医院启动湿实验；同时在算法改进阶段确保新算法在主队列上对这批核心靶点具有更高的排序稳定性与可解释性，最终在毕业论文中实现“算法预测 -> 生信互证 -> 湿实验证实”的完美合龙。
