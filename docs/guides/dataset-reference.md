# GSE252027 数据与论文参考

GSE252027 是小鼠心梗后总 RNA 系列，包含四类心脏细胞、六个采样时间点和 96 个提交文库。当前主分析使用 24 个成纤维细胞提交文库。详细文件格式、时间分组与筛选状态见 [数据手册](../../datasets/GSE252027/README.md)。

- [原始数据论文](https://doi.org/10.1038/s41597-025-05061-1)
